# Áudios dos personagens

Use arquivos MP3 seguindo este padrão:

- `char1-intro.mp3`: prévia tocada ao clicar no personagem no guia.
- `char1-power.mp3`: som usado quando o personagem ativa o poder.
- `char1-ko.mp3`: som opcional usado quando o personagem é eliminado.

Substitua `char1` por `char2` até `char30`. O sistema aceita os três tipos de evento; `intro` toca no guia e os arquivos `power` preparados abaixo já estão ligados às respectivas habilidades.
