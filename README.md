# Anime Neom Live

Publicação estática do palco 9:16 usado como fonte **Link** no TikTok LIVE Studio.

Link da arena publicada com a ponte local:

`https://erickhoga.github.io/anime-neom-live/?mode=live&studio=1&bridge=local#tiktok.studio`

O `iniciar-live.bat` atualiza a ponte local automaticamente e deve permanecer aberto para receber os eventos do TikFinity. A interface e as regras do jogo são carregadas da publicação online, portanto atualizações futuras normalmente exigem apenas recarregar a fonte Link.

O projeto principal, as configurações do APK e as credenciais de assinatura não fazem parte deste repositório.
